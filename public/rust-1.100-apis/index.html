RUST 1.100 / NEW STABLE APIS

標準APIの新しい道具を
WASMで試す

Rust 1.100で安定したAPIを、入力を変えながら実行します。すべての処理はブラウザ内のWASMで動きます。

WASMを読み込んでいます…

VEC::FROM_FN

インデックスからVecを作る

Vec::from_fn(length, |i| seed + i)

生成したVecを、同じ値を持つ借用Cowスライスと比較します。Rust 1.100で追加されたPartialEq実装を通ります。

—

BOOL::TOGGLE

値を直接切り替える

enabled.toggle();

開始値からトグルを10回行った結果。回数を変えて偶数・奇数回の違いを確認できます。

—

STR::TRIM_PREFIX / SUFFIX

前後の決まった文字を削る

text.trim_prefix("rust:")
    .trim_suffix(":wasm")

固定文字列から接頭辞と接尾辞を取り除いた残りのバイト数を計算します。

—

MEM::DROP_GUARD

スコープ終了時の処理

let guard = DropGuard::new(value,
    |owned| outcome = owned);
DropGuard::dismiss(guard);

通常終了ではクロージャが値を受け取り、dismissではクロージャを実行せず値を返します。

—

MEM::CONJURE_ZST

ゼロサイズ型を作る

unsafe { conjure_zst::<Marker>() }

不変条件のない空のMarker型だけを作ります。サイズは0バイト。値を作れない型や安全条件を持つ型には使えません。
