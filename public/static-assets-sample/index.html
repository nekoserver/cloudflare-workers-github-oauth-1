Workers Static Assets のサンプル

このページの HTML・CSS・JS は public/static-assets-sample/ に置いたファイルです。パスに一致するファイルがあるので、Worker のコードは動かずにエッジから直接返ります。

1. このページ自身(静的アセット)

読み込んだ各ファイルの応答ヘッダーを表示します。X-Static-Asset-Sample は public/_headers で付けたものです。

ファイル状態Content-TypeX-Static-Asset-Sample

2. 一致するファイルが無いパス(Worker が答える)

/api/static-assets-sample には対応するファイルが無いので、Worker のコードが JSON を返します。

(まだ呼んでいません)

設定(wrangler.toml)

assets = { directory = "./public" }

静的アセットへのリクエストは Worker の実行回数に数えられません。run_worker_first を付けると、アセットより先に Worker を動かせます(認証が必要なページなど)。
