RUST 1.100 / WEBASSEMBLY

値を返さない型、!

never型には値がありません。「失敗が存在しない」と「ここから戻らない」を、ブラウザ上の本物のWASMで試します。

WASMを読み込んでいます…

例: 42 → 通常終了 ／ 43 → ③だけtrap ／ 4294967295 → 32ビットすべて1

01 / ERROR IS IMPOSSIBLE

失敗しないResult

fn population(n: u32) -> Result<u32, !>

1のビット数を数えます。Err側の型が ! なので、エラー値を作れません。

—

02 / SAME TYPE

Infallibleと同じ型

let r: Result<u32, Infallible>
    = population(n);

Rust 1.100ではInfallibleは ! の別名。この代入をコンパイルしたWASMで、①と同じ計算を実行します。

—

03 / NO RETURN

戻らない分岐

if n.is_multiple_of(2) {
    n / 2
} else {
    stop() // -> !
}

偶数なら半分の値。奇数ならWASMのunreachable命令でtrapします。JSが例外を受け止めるので、入力を変えて再実行できます。

—

! と () は別の型です。() は「値が1つ」、! は「値が0個」。never型が必ずtrapするわけではなく、このサンプルが終了方法としてtrapを選んでいます。
