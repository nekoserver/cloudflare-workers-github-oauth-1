let mut values = Vec::new_in(Global);
values.push(value);
let boxed = Box::new_in(values, Global);

Vec::new_inとBox::new_inへGlobalを渡しています。WASMモジュールの中で確保し、使い終わった値はスコープを抜けると解放します。

ここではカスタムヒープを実装せず、Rustの標準Global allocatorを明示します。allocator自体はWASMのJavaScript境界を越えません。
