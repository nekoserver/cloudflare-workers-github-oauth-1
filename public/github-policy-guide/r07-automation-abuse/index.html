GITHUB POLICY / R07

スパム・不正な交流・自動化の濫用

特定リポジトリの規約適合性を確認するための日本語要約

運用評価 16 判定文

この要約はGitHubの公式訳ではありません。対象リポジトリの実査や合否判定は行っていません。適用条件と例外は原文で確認してください。

日本語要約

  • 過剰な自動大量処理、スパム、偽アカウント、不正な交流、自動スター・フォローによる順位操作、フィッシング等は禁止されます。報酬を利用した不正なエンゲージメントも対象になります。
  • レート制限を超えるためにAPIトークンを共有してはいけません。APIから得た情報をスパムや個人情報の販売等の禁止目的に利用することもできません。
  • 自動化やOAuthの採用自体を違反とする条項ではありません。実際の用途や活動を確認し、他人のIssueへの大量広告、GitHubサーバーでの迷惑な勧誘の中継、許可のないサービスアクセスの再販等も点検します。

リポジトリを確認する観点

このリポジトリに関連する実際の自動処理・交流・サービス利用が禁止行為に当たるか確認する。

確認する証拠

Actionsとアプリの実行記録、API履歴、スター・フォロー活動、投稿履歴、トークンの運用、書面許可

判断の限界

自動化やOAuthという方式だけで禁止行為とは判断しない。採掘・不正な順位操作等の用途と実態を確認する。

実査では「適合」「不適合」「未確認」「適用外」を区別します。証拠がない項目を適合とは扱いません。

対応する二値判定文

Yes／Noは「規約の記述として正しいか」の解答です。対象リポジトリの適合・不適合の判定結果ではありません。
