GITHUB POLICY / R14

GitHubの権利・保証・執行措置

特定リポジトリの規約適合性を確認するための日本語要約

リポジトリの直接判定対象外 23 判定文

この要約はGitHubの公式訳ではありません。対象リポジトリの実査や合否判定は行っていません。適用条件と例外は原文で確認してください。

日本語要約

  • GitHubはサービスを現状有姿かつ提供可能な状態で提供し、中断がないこと、エラーの不存在、特定の時刻・場所での利用可能性等を保証していません。ベータ機能にも通常と同じサポートや安全対策が保証されるわけではありません。
  • 規約にはGitHubによる停止・終了、コンテンツ削除、サービス変更・廃止の権利や、責任制限が記載されています。重大な規約変更の30日前通知と、サービス自体の変更・廃止についての定めは区別します。
  • GitHubが停止できることと、特定リポジトリが実際に違反していることは別です。障害や404だけから違反を導かず、執行の説明や証拠を確認します。制限に対する復旧・異議申立ての手続も参照できます。

リポジトリを確認する観点

GitHubの保証範囲、変更・削除・停止の権利、異議申立てを理解するために参照する。

確認する証拠

規約、サービスの提供状況、GitHubからの通知、執行理由、異議申立ての記録

判断の限界

GitHubに停止権があることと、対象リポジトリが規約違反であることは別の命題である。

実査では「適合」「不適合」「未確認」「適用外」を区別します。証拠がない項目を適合とは扱いません。

対応する二値判定文

Yes／Noは「規約の記述として正しいか」の解答です。対象リポジトリの適合・不適合の判定結果ではありません。
