GITHUB POLICY / R13

解約・法的手続・契約一般

特定リポジトリの規約適合性を確認するための日本語要約

手続・契約背景 25 判定文

この要約はGitHubの公式訳ではありません。対象リポジトリの実査や合否判定は行っていません。適用条件と例外は原文で確認してください。

日本語要約

  • アカウントの解約は設定画面から行います。解約後の情報の保持・削除には法的義務等の例外があり、他人のリポジトリへの投稿や他人のforkは解約によって必ず削除されるものではありません。
  • 終了・解約・ダウングレード後の適法なコンテンツの写しは、90日以内に依頼した場合の合理的な提供努力の対象です。必ず取得できるという保証ではありません。正式な法的通知は通常のサポート連絡とは区別されます。
  • 権利義務の譲渡、補償、準拠法、条項の存続等は、契約や手続の問題として確認します。これらは通常、リポジトリのファイルだけで適合性を判断できる事項ではありません。

リポジトリを確認する観点

解約、写しの請求、法的通知、権利譲渡等が実際に生じた場合に手続を確認する。

確認する証拠

契約、解約日時、請求日時、法的通知と送達記録、譲渡への書面同意、紛争資料

判断の限界

これらの手続が発生していないリポジトリに一律の合否項目として課さない。

実査では「適合」「不適合」「未確認」「適用外」を区別します。証拠がない項目を適合とは扱いません。

対応する二値判定文

Yes／Noは「規約の記述として正しいか」の解答です。対象リポジトリの適合・不適合の判定結果ではありません。
