GITHUB POLICY / R04

非公開情報・秘密保持・公開範囲

特定リポジトリの規約適合性を確認するための日本語要約

条件付き評価 26 判定文

この要約はGitHubの公式訳ではありません。対象リポジトリの実査や合否判定は行っていません。適用条件と例外は原文で確認してください。

日本語要約

  • GitHubは非公開リポジトリの内容を機密として扱い、アクセスは利用者が管理します。ただし、セキュリティ対策、既知の脆弱性等の調査、サポート、サービスの完全性の維持、一定の法的義務への対応では、担当者が同意なしでアクセスする場合があります。
  • 非公開内容へのアクセス通知には、自動スキャンやセキュリティ対応等の例外があります。追加機能の有効化や、GitHubのAI機能への入力としての提供によって、追加のアクセスやデータ利用が生じる場合があります。
  • 非公開ベータの非公開情報は、機密表示の有無にかかわらず、原則としてテスト・評価目的に限って扱い、合理的な安全対策を取ります。既知情報、公知情報、独自開発、許可を得た開示等の例外は個別に確認します。

リポジトリを確認する観点

非公開情報や非公開ベータ情報の取り扱いについて、適用義務を確認する。

確認する証拠

公開範囲と変更履歴、秘密保持の対象情報、GitHubへの同意、開示許可、GitHubのアクセス通知

判断の限界

Eの多くはGitHub側の義務・アクセス例外である。非公開設定だけで契約遵守や機密保持全体を証明しない。

実査では「適合」「不適合」「未確認」「適用外」を区別します。証拠がない項目を適合とは扱いません。

対応する二値判定文

Yes／Noは「規約の記述として正しいか」の解答です。対象リポジトリの適合・不適合の判定結果ではありません。
