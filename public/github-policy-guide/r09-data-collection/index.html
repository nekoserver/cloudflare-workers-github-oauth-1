GITHUB POLICY / R09

情報収集・個人情報の利用と対応

特定リポジトリの規約適合性を確認するための日本語要約

運用評価 9 判定文

この要約はGitHubの公式訳ではありません。対象リポジトリの実査や合否判定は行っていません。適用条件と例外は原文で確認してください。

日本語要約

  • GitHubの情報をスパムに使うことは、API、スクレイピング、その他の収集方法を問わず禁止されます。AUP上では、API経由の収集はスクレイピングの定義から区別されています。
  • 収集した個人情報は、本人が許可した目的のためにのみ利用し、合理的に保護する必要があります。苦情、削除要求、連絡拒否の要求には迅速に対応します。
  • 公開された非個人情報の研究利用について、AUP 7に示された許可には成果出版物をオープンアクセスにする条件があります。公開情報の保存目的の利用も記載されていますが、これらをあらゆる用途の包括的許可とは扱いません。

リポジトリを確認する観点

GitHubから得た情報の収集・利用・保護・苦情対応が適用条件を満たすか確認する。

確認する証拠

収集元、収集方法、利用目的、本人の許可、安全対策、削除・連絡拒否への対応、研究成果

判断の限界

APIを利用していることは個人情報の目的外利用を許可しない。AUP 7の研究例を全研究の包括判断にしない。

実査では「適合」「不適合」「未確認」「適用外」を区別します。証拠がない項目を適合とは扱いません。

対応する二値判定文

Yes／Noは「規約の記述として正しいか」の解答です。対象リポジトリの適合・不適合の判定結果ではありません。
