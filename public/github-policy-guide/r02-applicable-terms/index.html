GITHUB POLICY / R02

適用契約・追加規約・連携先

特定リポジトリの規約適合性を確認するための日本語要約

適用条件 11 判定文

この要約はGitHubの公式訳ではありません。対象リポジトリの実査や合否判定は行っていません。適用条件と例外は原文で確認してください。

日本語要約

  • 適用される法律に加え、GitHubの利用規約、Acceptable Use Policies、Community Guidelinesに従う必要があります。契約形態や使う機能によって、製品別の追加条項が適用されます。
  • 外部アプリを介してGitHub APIへアクセスする場合にもAPI条項が適用されます。一方、その外部アプリと利用者の関係には、第三者側の規約も適用され得ます。
  • GitHubのAI条項を外部AI一般の契約として扱うことはできません。個人ライセンス、GitHub Customer Agreement、ボリュームライセンス等のどれが適用されるかを先に確認します。

リポジトリを確認する観点

このリポジトリの所有者・製品利用・連携先に適用される契約を確定する。

確認する証拠

契約種別、GitHubプラン、利用製品、アプリ一覧、第三者の契約

判断の限界

GitHub規約だけで外部サービスの契約や製品別追加条項まで評価したことにしない。

実査では「適合」「不適合」「未確認」「適用外」を区別します。証拠がない項目を適合とは扱いません。

対応する二値判定文

Yes／Noは「規約の記述として正しいか」の解答です。対象リポジトリの適合・不適合の判定結果ではありません。
