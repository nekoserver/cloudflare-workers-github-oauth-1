GITHUB POLICY / R12

所有者の支払い・プラン変更

特定リポジトリの規約適合性を確認するための日本語要約

条件付き評価 14 判定文

この要約はGitHubの公式訳ではありません。対象リポジトリの実査や合否判定は行っていません。適用条件と例外は原文で確認してください。

日本語要約

  • 利用者は、契約した有料プランや従量利用に関する料金・税等を支払う責任を負います。有料アカウントには有効な支払い手段が必要ですが、無料アカウントには支払い情報の登録は必須ではありません。
  • 合意したサブスクリプション料金は支払期間中維持され、期間終了時には変更され得ます。月払い・年払いは前払い、一定の追加従量利用は実際の利用量に基づく後払いです。L.3には日割りや未使用月等の返金をしない旨が記載されています。
  • 有料化や上位プランへの変更には即時請求等の条件があります。ダウングレードではコンテンツ、機能、容量へのアクセスを失う場合があります。請求書払いの期限や遅延利息等も、適用契約と法令を併せて確認します。

リポジトリを確認する観点

有料機能を使う所有者の支払義務とプランの条件を確認する。

確認する証拠

適用プラン、請求書、利用量、支払手段、決済記録、プラン変更記録

判断の限界

支払義務はアカウントや契約の問題であり、コードそのものの違反とは区別する。

実査では「適合」「不適合」「未確認」「適用外」を区別します。証拠がない項目を適合とは扱いません。

対応する二値判定文

Yes／Noは「規約の記述として正しいか」の解答です。対象リポジトリの適合・不適合の判定結果ではありません。
