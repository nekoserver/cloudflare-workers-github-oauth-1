GITHUB POLICY / R01

所有者・アカウント・管理責任

特定リポジトリの規約適合性を確認するための日本語要約

条件付き評価 26 判定文

この要約はGitHubの公式訳ではありません。対象リポジトリの実査や合否判定は行っていません。適用条件と例外は原文で確認してください。

日本語要約

  • 登録には有効なメールアドレスが必要です。通常の個人アカウントのログイン共有は認められず、作成者は人間でなければなりません。人間が責任を持って作成する自動処理専用のマシンアカウントには例外があります。
  • 年齢、無料アカウントの保有数、契約で認められた席数、輸出管理や制裁法の要件にも従う必要があります。Organizationの所有者は、そのOrganizationで行われる活動について責任を負います。
  • 所有者はアカウントとパスワードの安全を保ち、不正利用を知った場合は速やかにGitHubへ通知します。これらの適合性は、ソースコードだけでは確定できません。

リポジトリを確認する観点

所有者と実際の利用者、登録・共有・自動化アカウント、セキュリティ対応を確認する。

確認する証拠

所有者情報、アカウント作成経緯、Organization設定、アクセス記録、不正利用対応記録

判断の限界

リポジトリのコードから年齢、登録情報、保有アカウント数などは判断できない。

実査では「適合」「不適合」「未確認」「適用外」を区別します。証拠がない項目を適合とは扱いません。

対応する二値判定文

Yes／Noは「規約の記述として正しいか」の解答です。対象リポジトリの適合・不適合の判定結果ではありません。
