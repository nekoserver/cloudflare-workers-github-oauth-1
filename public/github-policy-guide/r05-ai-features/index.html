GITHUB POLICY / R05

GitHubのAI機能・訓練設定・アクセス相互主義

特定リポジトリの規約適合性を確認するための日本語要約

条件付き評価 15 判定文

この要約はGitHubの公式訳ではありません。対象リポジトリの実査や合否判定は行っていません。適用条件と例外は原文で確認してください。

日本語要約

  • GitHubはAI機能の入力・出力の所有権を主張しませんが、出力の正確性、安全性や権利侵害がないことは保証しません。利用者は使用前に出力をレビューし、テスト・検証する責任を負います。
  • 個人ライセンス向けの入力・出力の訓練等への利用には、設定によるオプトアウトが用意されています。効果は将来に向けたもので、公開リポジトリのコンテンツに関する別の許諾まで取り消すものではありません。
  • 商用AIの開発・訓練のための自動アクセスには、D.9のアクセス相互主義が適用される場合があります。学術研究のみのアクセスや、関連会社を含む規定の事業者規模が月間7億人未満の場合の適用除外を先に確認します。

リポジトリを確認する観点

GitHubのAI機能の使用有無、適用契約、入力・出力とその検証、D.9の適用を確認する。

確認する証拠

AI利用記録、レビュー・テスト記録、オプトアウト設定、商用AI開発の用途、事業者規模

判断の限界

外部AI一般にJを拡張しない。訓練への同意・オプトアウトの選択自体を違反としない。

実査では「適合」「不適合」「未確認」「適用外」を区別します。証拠がない項目を適合とは扱いません。

対応する二値判定文

Yes／Noは「規約の記述として正しいか」の解答です。対象リポジトリの適合・不適合の判定結果ではありません。
