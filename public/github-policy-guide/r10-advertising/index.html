GITHUB POLICY / R10

広告・宣伝・収益化

特定リポジトリの規約適合性を確認するための日本語要約

直接評価＋運用 5 判定文

この要約はGitHubの公式訳ではありません。対象リポジトリの実査や合否判定は行っていません。適用条件と例外は原文で確認してください。

日本語要約

  • GitHubでの広告・宣伝は全面禁止ではありません。ただし、アカウントを通じて掲載するコンテンツの主目的を広告宣伝にしてはいけません。PagesやPackages等も対象です。
  • READMEやプロジェクトの説明には、そのプロジェクトに関連する静的な宣伝画像、リンク、文章を掲載できます。他人のアカウントへの広告や、規約で禁止される大量宣伝は認められません。
  • 宣伝物を掲載する側は、適用される広告関連法令に従う責任があります。広告の有無だけで適合性を決めず、プロジェクトとの関係、主目的、表示内容、配信方法を確認します。

リポジトリを確認する観点

コンテンツの主目的、宣伝とプロジェクトの関係、広告法令への適合を確認する。

確認する証拠

README、Pages、Packages、リポジトリ説明、宣伝物、広告配信・投稿の運用、関連法令

判断の限界

広告の存在だけで不適合としない。他人のIssueへの大量広告はR07でも扱う。

実査では「適合」「不適合」「未確認」「適用外」を区別します。証拠がない項目を適合とは扱いません。

対応する二値判定文

Yes／Noは「規約の記述として正しいか」の解答です。対象リポジトリの適合・不適合の判定結果ではありません。
