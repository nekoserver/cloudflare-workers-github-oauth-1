GITHUB POLICY / R06

有害・違法な内容・嫌がらせ・なりすまし

特定リポジトリの規約適合性を確認するための日本語要約

直接評価＋文脈 16 判定文

この要約はGitHubの公式訳ではありません。対象リポジトリの実査や合否判定は行っていません。適用条件と例外は原文で確認してください。

日本語要約

  • 違法行為の促進、性的搾取・虐待、中傷、詐欺、差別、嫌がらせ、暴力の脅迫・扇動、不必要な暴力の美化等は禁止されます。虚偽情報については、公共の利益への悪影響等の条件も確認します。
  • GitHubの従業員を含め、人や組織を装う行為や、GitHubとの関係を偽る行為は禁止されます。第三者の個人情報の無断投稿等によるプライバシー侵害も認められません。
  • 評価対象には、コードだけでなく、README、説明文、Issue、PR、コメント等の関連する投稿と行為も含めます。特定の語句があるだけで判断せず、実際の内容、文脈、許可や権利を確認します。

リポジトリを確認する観点

ファイル、公開文書、Issue等の投稿に、禁止される内容・行為があるか確認する。

確認する証拠

対象時点のファイル、Issue、PR、コメント、プロフィール・説明、会話の文脈、許諾

判断の限界

単語一致だけで違反としない。個人情報の公開については同意やプライバシー侵害の成立も確認する。

実査では「適合」「不適合」「未確認」「適用外」を区別します。証拠がない項目を適合とは扱いません。

対応する二値判定文

Yes／Noは「規約の記述として正しいか」の解答です。対象リポジトリの適合・不適合の判定結果ではありません。
